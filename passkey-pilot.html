NEW IBERIA POLICE DEPARTMENT

Passkey Authentication Pilot

Workforce staging — device enrollment and sign-in testing only

Not an operational login replacement. The NIPD workforce dashboard still requires the existing protected authentication. This pilot must not be used for real employee invitations or provisioning.

1. Sign in with a passkey

Use Face ID, fingerprint or your phone's device PIN. A passkey alone does not yet unlock protected workforce modules.

No passkey sign-in attempted.

2. Enroll a passkey on an existing test account

Enrollment requires an already confirmed account and a current authenticated session with the existing staging MFA. This section never creates a new user.

Sign in using existing staging authentication before enrolling.

3. Device recovery

An employee who loses their phone must have the old passkey revoked by a separately authorized administrator, complete identity verification and enroll a new passkey. Administrator reset is not yet activated in this pilot.
